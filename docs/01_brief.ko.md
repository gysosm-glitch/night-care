# 프로젝트 브리프

English: [01_brief.md](01_brief.md)

> 초안 (Claude 작성) — 팀 검토 후 이 줄을 지우세요.

## 목표
충북대생이 **밤에 집에 갈 때 도보·버스·택시·안심귀가 동행 중 무엇으로 갈지 결정하도록 돕고, 도착할 때까지 함께한다.**
에이전트는 정보를 나열하는 데서 끝나지 않는다. **도구**로 사실(위험도, 경로, 막차, 요금, 열린 안전시설)을 모으고, 모든 답을 **분명한 추천 하나와 그 이유**로 마무리한다.

## 사용자와 상황
캠퍼스 근처(개신동/사창동/복대동/봉명동/율량동)에서 혼자 사는 충북대생. 기술에 익숙하지 않고, 지치거나 불안한 상태로 휴대폰으로 읽는다. 중요한 상황은 세 가지다.

| 상황 | 필요한 것 | 답하는 방식 |
|---|---|---|
| **출발 전** — "알바 끝났어, 사창동까지 걸어가도 돼?" | 결정: 도보 / 버스 / 택시 / 동행 | 추천을 먼저, 근거 2~3개 |
| **걷는 중 불안할 때** — "누가 따라오는 것 같아" | 지금 바로 갈 수 있는 가장 가까운 안전시설 | 112를 먼저, 장소 하나, 분석 생략 |
| **미리 계획할 때** — "내일 밤 11시 안심귀가 신청해 줘" | 동행 신청 / 조회 / 취소 | 바꾸기 전에 반드시 확인 |

## 에이전트가 할 수 있는 것
### v1 — 구현됨
- 동네별 **실제 지구대·119안전센터**를 전화번호·주소와 함께 찾기 (공공데이터포털)
- 충북대 정문에서 가는 길 안내: 도보 시간, 가로등 비율, CCTV 수, 버스 노선과 막차
- 동네와 시각에 따른 **걷기 위험도 점수(0~100)**와 이유
- 22:00~04:00 심야 할증을 포함한 택시비 계산
- **위급 모드** (`get_emergency_guide`): 지금 할 일, 가장 가까운 지구대, 바로 보낼 수 있는 112 문자 문구
- **귀가 기록과 도착 확인** (`start_trip`, `check_arrival`): 도착 예정 시각, 보호자에게 보낼 메시지, 늦어지면 경고
- **안심귀가 동행 신청** 저장 (사용자가 확인한 뒤에만, 22:00~01:00에만)
- 비교 계산 (예: 버스와 택시 요금 차이)
- 앱 사이드바: 한 번에 누르는 112 전화·문자 버튼, 근처 지구대·119, 사용 설명서

### v2 — 계획 (우선순위 순)
1. **알려 주기보다 추천하기.** "어떻게 가?" 질문에는 항상 도보 / 버스 / 택시 / 동행 중 하나를 추천하며 끝낸다. (프롬프트 규칙은 추가함. 계속 점검 필요)
2. **실제 시설 더 넣기.** 공공데이터포털의 응급실·안전비상벨 추가, 청주의 나머지 119안전센터 13곳을 동네와 연결, 빠져 있는 개신동 지구대 채우기.
3. **시각 입력 없이 쓰기.** `get_current_time` 도구 — "23:10" 대신 "지금"이라고만 해도 된다.
4. **출발지 늘리기.** `origin` 매개변수: 정문, 중문, 후문 (각각 다른 경로).
5. **동행 신청 관리.** `list_escort_requests`, `cancel_escort` (쓰기 도구, 먼저 확인).
6. **위험도 점수 보강.** 주말과 (가상) 날씨 반영 — 비가 오면 시야와 인적이 줄어든다.

## 범위 밖
- 실시간 API(경찰청, 공공데이터, 버스, 지도), 실시간 GPS 추적, 사용자 대신 112 신고나 친구에게 메시지 보내기, 결제, 여러 사용자 / 로그인
- 지구대·파출소(충북경찰청, 2026-08-03)와 119안전센터(소방청, 2026-07-01)는 공공데이터포털 파일을 한 번 변환해 `data/safe_spots.json`에 넣었다. 경로, 위험도 입력값, 요금, 안심귀가 서비스는 가상 데이터다. 가상 장소는 보여 주지 않는다. 실시간 API 호출은 없다.
- 에이전트는 어떤 길도 "100% 안전하다"고 말하지 않고, 112를 대신하지 않는다.

## 카페 에이전트가 아닌 이유 (이름만 바꾸기 테스트)
`estimate_walk_risk` → "라떼까지 걸어가면 얼마나 위험해?", `find_safe_spots` → "크루아상 파는 지구대는?"으로 바꾸면 둘 다 카페에서는 말이 안 된다.
카페 사장님에게는 "23:30에 어둡고 사람 없나", "근처에 열린 지구대 있나", "112에 뭐라고 문자 보내지"(`get_emergency_guide`), "집에 잘 도착했나"(`check_arrival`)가 필요 없다.

## 성공 기준
- **추측하지 않기:** 시각, 위험도, 요금, 장소는 모두 도구에서 나온다.
- **결정해 주기:** "걸어가도 돼?"에 대한 답은 추천 하나(도보 / 버스 / 택시 / 동행)와 이유로 시작한다.
- **연속 호출:** 도구 3개를 이어 써야 하는 질문(위험도 → 경로 → 택시)에 답할 수 있다.
- **위급 상황:** "따라오는 것 같아"에는 **첫 줄**에 112와 열린 안전시설 하나를 알려 주고, 도구는 최대 1번만 부른다.
- **오류 회복:** 도구 오류(없는 동네, 운영시간 22:00~01:00 밖의 동행 신청)가 나면 다시 시도하거나 분명하게 되묻고, 절대 멈추지 않는다.
- **안전한 저장:** 사용자가 "응"이라고 하기 전에는 아무것도 저장하지 않는다 (`request_escort`, `start_trip`; v2 `cancel_escort`).
- **짧게:** 답은 휴대폰 한 화면 안에 들어간다 (5줄 안팎, 필요하면 목록 추가).
