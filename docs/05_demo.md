## 도구 설명 준비 (교수님 지목 대비)
- **estimate_walk_risk (B)**: 시간대 + 가로등 + CCTV + 인적 + 도보 거리 공식. LLM이 아니라 코드가 계산해서 매번 같은 결과, `reasons`로 근거 제공.
- **find_safe_spots (A)**: 공공데이터포털 CSV를 한 번 변환한 실제 지구대·119만 반환. 가상 장소 없음. 개신동은 데이터에 없어서 112 힌트.
- **get_emergency_guide (A)**: 위급할 땐 분석 생략. 할 일 3개 + 가까운 시설 최대 2곳 + 112 문자 문구.
- **start_trip / check_arrival (B)**: 확인 후 저장, 도착 예정 시각과 보호자 메시지 생성. 예정보다 10분 넘게 늦으면 overdue. 자정을 넘는 시간도 처리.
- **request_escort / get_escort_info (B)**: `confirmed`로 확인 없는 저장을 코드에서 막음. 운영시간(22–01시) 검사, 목적지 관할 지구대 연결, 요원 확인법 안내. 데모라 실제 전달 안 된다고 명시.
- **estimate_taxi_cost (B)**: `(4800 + 150×max(0, 분−5)) × 1.2`(22–04시), 100원 반올림.
