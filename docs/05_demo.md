# 3-minute demo script (한 팀 2명)

| 시간 | 할 일 | 입력 / 내용 |
|---|---|---|
| 0:00–0:20 | **한 문장 소개** | "밤이나 주말에 아픈 충북대생이, 지금 열린 병원·약국과 가는 법, 택시비를 한 번에 알 수 있는 에이전트입니다." |
| 0:20–1:20 | **3-tool 시나리오 A** (`streamlit run src/app.py`로 도구 호출 펼쳐 보이기) | `지금 밤 11시 10분인데 열이 나. 갈 곳이랑 택시비 알려줘` → find_open_places → get_route → estimate_taxi_cost (9,400원) |
| 1:20–2:10 | **오류 시나리오 B** | `밤 11시인데 치과 열린 곳 있어?` → 오류 힌트를 읽고 회복하는 모습 |
| 2:10–3:00 | **도구 설명 (교수자가 지목)** | 아래 예상 질문 참고 |

## 도구 설명 준비 (왜 이 매개변수? 왜 이 오류 문구?)
- **find_open_places (A)**: `time`을 받는 이유 = "지금 열려 있나"는 시각이 없으면 답할 수 없음. 과목을 고정 목록으로 받고, 오류에 유효 과목 목록을 넣은 이유 = LLM이 다음 시도에서 고를 수 있게. 결과는 열린 곳만(요약) 반환.
- **get_route (A)**: `time`은 선택 → 주면 `bus_available_now`를 계산해 LLM이 막차 비교를 직접 하지 않게 함. 오류에 유효 지역 4곳 안내.
- **estimate_taxi_cost (B)**: 심야할증을 LLM 암산에 맡기지 않고 코드로 계산(정확성). 공식 `(4800 + 150×max(0, 분−5)) × 1.2`, 100원 반올림. 22:00–04:00은 자정을 넘는 구간이라 `now >= 22:00 or now < 04:00`으로 판정.
- **book_visit_plan (B)**: `confirmed` 매개변수 = 코드 단에서 확인 없는 쓰기를 막는 안전장치. 운영시간 밖 예약은 오류 + "다른 시간" 힌트.
