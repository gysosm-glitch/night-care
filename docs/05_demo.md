# 3-minute demo script (한 팀 2명)

> 초안 (Claude 작성) — 팀 검토 후 이 줄을 지우세요.

| 시간 | 할 일 | 입력 / 내용 |
|---|---|---|
| 0:00–0:20 | **한 문장 소개** | "밤늦게 혼자 귀가하는 충북대생이, 걸어가도 괜찮은지와 들를 수 있는 안전한 곳, 막차·택시비, 안심귀가 신청까지 한 번에 해결하는 에이전트입니다." |
| 0:20–1:20 | **3-tool 시나리오 A** (`python -m streamlit run streamlit_app.py`로 도구 호출 펼쳐 보이기) | `지금 밤 11시 10분인데 사창동까지 걸어가도 괜찮을까?` → estimate_walk_risk (82, 높음) → get_route (막차 지남) → estimate_taxi_cost (9,400원) |
| 1:20–2:10 | **확인 후 쓰기 시나리오 C** | `내일 밤 11시에 정문에서 사창동까지 안심귀가 신청해 줘` → 확인 질문 → "응" → request_escort |
| 2:10–3:00 | **도구 설명 (교수자가 지목)** | 아래 예상 질문 참고 |

## 도구 설명 준비 (왜 이 매개변수? 왜 이 오류 문구?)
- **find_safe_spots (A)**: `time`을 받는 이유 = 안심지킴이집처럼 밤에만 여는 곳이 있어 "지금 열려 있나"는 시각 없이 답할 수 없음. 자정을 넘는 운영시간(18:00–01:00)도 `in_window`로 처리. 열린 곳이 없으면 112 안내 힌트.
- **get_route (A)**: 도보 시간과 함께 가로등 비율·CCTV 수를 돌려줘 LLM이 "어두운 길"을 지어내지 않게 함. `time`을 주면 `bus_available_now`를 코드가 계산.
- **estimate_walk_risk (B)**: 카페에는 절대 없는 도구. 시간대·가로등·CCTV·인적·도보 거리를 정해진 공식으로 점수화해서 매번 같은 입력에 같은 답. 점수와 함께 `reasons`를 줘서 LLM이 이유를 설명할 수 있게 함.
- **estimate_taxi_cost (B)**: 심야할증을 LLM 암산에 맡기지 않고 코드로 계산. `(4800 + 150×max(0, 분−5)) × 1.2`, 100원 반올림.
- **request_escort (B)**: `confirmed` 매개변수 = 코드 단에서 확인 없는 쓰기를 막는 안전장치. 운영시간(22:00–01:00) 밖이면 오류 + "택시 제안" 힌트.
